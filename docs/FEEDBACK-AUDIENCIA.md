`npm run context` muestra las reglas activas antes de escribir cada guion y son obligatorias.

Quién lo escribe: el Estratega de contenido, una vez por semana, a partir de `marketing/informes/`. Propone el cambio como borrador en The Brain y **solo se guarda cuando Nacho lo aprueba**, porque cambia lo que se publica al día siguiente.

Formato: como mucho 8 reglas. Cada una en una línea, con el dato que la respalda y la fecha:
`- <regla concreta para el guion> (dato: <cifra y reels comparados>; <AAAA-MM-DD>)`
